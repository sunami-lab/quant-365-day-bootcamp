# Master resource list — 365-Day Quant Bootcamp

Every URL here was fetched and confirmed live between 6 and 7 August 2026. **Use only these URLs**, with
the `label` and `url` copied exactly. The site deduplicates by URL, so a trailing slash that differs
creates a phantom second entry on the resources page.

If you genuinely need something not on this list, verify it with WebFetch first. Do not guess URL
patterns — a previous verification pass constructed two plausible identifiers and got a paper about
financial education in Ghana and a neutrino-cosmology preprint.

The `kind` column is what goes in the day record. Allowed values: `textbook`, `paper`, `course`,
`video`, `repo`, `tool`, `data`, `problems`, `reference`.

## Do not use

These were checked and are wrong, dead, or traps. Named here so nobody re-derives them.

- **`quantopian/zipline`, `/pyfolio`, `/alphalens`, `/empyrical`** — abandoned since 2020 (last releases
  2019–2020). Not formally archived, which misleads. Use the `stefan-jansen/*-reloaded` forks above.
- **`quantopian/trading_calendars`** — dead since Jan 2021. Use `gerrymanoim/exchange_calendars`.
- **`mementum/backtrader`** — no commits since April 2023. Docs are excellent, package still installs,
  but do not build new work on it.
- **`hudson-and-thames/mlfinlab`** — no longer open source; £100/month. Implement López de Prado's
  methods yourself, which is better practice anyway.
- **`rlabbe/filterpy`** — last release 2018. The companion *book* is excellent and maintained; the
  library is not. Use `statsmodels.statespace` in production.
- **`mibian`** — dead since 2016. Use `py_vollib` or QuantLib.
- **`erdewit/ib_insync`** — genuinely archived in March 2024 after the author died. Use `ib_async`.
- **`financepy.com`** — parked domain that redirects to a domain-sale page. Link the GitHub repo only.
- **`pysystemtrade.co.uk`** — does not resolve. The repo also moved orgs: `robcarver17` → `pst-group`.
- **`kevinsheppard.com`** — did not respond. Use the `bashtage.github.io/kevinsheppard.com/` mirror.
- **`leanpub.com/quantlibpython`** — resolves, but is a *different, unpublished* book. The free cookbook
  is at `/quantlibpythoncookbook`.
- **`quantresearch.org/VPIN.pdf`** — live, but a short explainer, not the Easley–López de Prado–O'Hara
  paper. Do not cite it as the paper.
- **`hastie.su.domains/.../ESLII.pdf`** — 404. The *Elements of Statistical Learning* free PDF is broken
  on the author's current host. Use *Introduction to Statistical Learning* instead.
- **`papers.ssrn.com/*`** — 403 to every automated fetcher. Find another host or use the DOI.
- **`udacity.com/course/machine-learning-for-trading--ud501`** — the free Georgia Tech ML4T course is
  gone; it redirects to a paid nanodegree.
- **`oyc.yale.edu/economics/econ-252-11`** — 404. The working course home is `/economics/econ-252`.
- **`stat110.hsites.harvard.edu`** and **`projects.iq.harvard.edu/stat110`** — 403 to fetchers, so the
  strategic-practice problem sets could not be confirmed. Use the YouTube playlist.
- **`polygon.io`** — renamed **Massive** on 30 October 2025; every polygon.io URL now redirects. The old
  keys and `api.polygon.io` still work, but any tutorial linking polygon.io lands on different branding.
- **`crsp.org`** — redirects to `indexes.morningstar.com`. Morningstar completed its acquisition of CRSP
  from the University of Chicago in February 2026. The research database is reached through WRDS, not
  crsp.org.
- **`iexcloud.io`** — shut down 31 August 2024. Still the default data source in a large number of
  still-published tutorials.
- **`quantopian.com`** — does not resolve. Closed in 2020. The lecture notebooks survive on GitHub.
- **Quandl WIKI prices** (`data.nasdaq.com/data/WIKI-*`) — 404. Stopped updating in April 2018 and the
  dataset page is gone. Still the default example in older zipline bundles.
- **Alpha Vantage** — not dead but badly degraded: the free tier is now 25 requests per day, and both
  intraday and adjusted-daily are premium. Any text describing its old 5/min, 500/day tier is wrong.
- **`data.lobsterdata.com`** — NXDOMAIN. Every `data.lobsterdata.com/info/*.php` link is dead, including
  ones search engines still return. The live site is a single-page app where every path returns 200 with
  identical HTML, so dead paths look alive. Sample data is now gated behind an email request.
- **`github.com/optiver/ready-trader-go`** — 404; the competition last ran in 2023 and Optiver's GitHub
  org has no RTG repository. Use the community mirror.
- **QuantConnect Quant League** — discontinued after Q4 2025. QuantConnect belongs here as free
  backtesting infrastructure, not as a live competition.
- **`openbb.co`** — presented a TLS certificate mismatch. Use the GitHub repo as the canonical link, and
  note the "OpenBB Terminal" no longer exists as a product name.
- **`math.nyu.edu/~gatheral/`** — 403. Gatheral's material now lives at `jgatheral.github.io`.
- **`mfe.baruch.cuny.edu/jgatheral/`** — serves an incomplete TLS certificate chain, so it fails
  verification and a reader's browser may warn. The page is only a faculty bio in any case;
  `jgatheral.github.io` has the actual lecture slides and is clean.
- **`hastie.su.domains/.../ESLII.pdf`** — 404, as noted above. `hastie.su.domains/CASI/` and the ISLR
  download wrappers do work.
- **Bruce Hansen's *Econometrics* and *Probability and Statistics for Economists*** — no longer free;
  both were published by Princeton UP in 2022 and his pages now carry purchase links only.

Three sites return 403 to automated fetchers but are genuinely live and fine in a browser:
`matplotlib.org`, `cppreference.com`, and the `*.ml4trading.io` documentation.
